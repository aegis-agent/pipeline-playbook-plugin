# Pipeline Playbook Plugin

Claude Code plugin for @pipelineabuser-inspired prospecting, competitive intel, and growth tactics.

## Overview

This plugin implements the Pipeline Playbook methodology, providing tactical workflows for:

- Prospecting and lead generation
- Competitive intelligence
- Growth hacking
- Acquisition strategies
- Market research

## Installation

```bash
claude plugin install aegis-agent/pipeline-playbook-plugin
```

## Skills

| Skill | Command | Purpose |
|-------|---------|---------|
| **prospect** | `/prospect` | High-intent lead discovery from hiring signals |
| **spy** | `/spy` | Competitor monitoring for complaints |
| **growth** | `/growth` | 30-day parasitic Twitter growth plan |
| **validate** | `/validate` | Rapid offer validation before building |
| **versus** | `/versus` | SEO comparison content generation |
| **clone** | `/clone` | SaaS reverse engineering playbook |
| **outbound** | `/outbound` | Cold email campaign builder |
| **intent** | `/intent` | Buying intent detection (2.7% bookmark rate) |
