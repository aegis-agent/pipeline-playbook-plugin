# /validate - Rapid Offer Validation

Validate a business idea before investing time building it.

## Philosophy

> "The fastest way to get testimonials before you have customers is to give your thing away free to 20 people."

## Usage

```
/validate "<offer description>"
```

### Examples

```bash
/validate "AI-powered code review tool for Python"
/validate "Twitter ghostwriting for founders"
/validate "Course on cold email for B2B SaaS"
```

## Validation Matrix

| Signal | Threshold |
|--------|----------|
| Demand signals | >20 tweets/week |
| Competitor complaints | >10 actionable |
| Similar products exist | Yes (validates market) |
| Price point sustainable | >$50/mo possible |
| Can build MVP in <2 weeks | Yes |

**Decision:** 4-5 green = GO, 2-3 = MAYBE, 0-1 = NO-GO
