# /versus - Comparison Content Generator

Generate 4000+ word SEO comparison content.

## Philosophy

> "Create a '[competitor] vs [you]' comparison page. You show up when people search alternatives, you control the narrative."

## Usage

```
/versus "<your_product>" "<competitor1>" "<competitor2>"
```

### Examples

```bash
/versus "our-crm" "salesforce" "hubspot" "pipedrive"
/versus "our-tool" "tool1" "tool2" "tool3"
```

## Target Keywords

- "[competitor] vs [you]"
- "[competitor] alternatives"
- "[competitor] competitors"
- "best [category] software"
- "[competitor] pricing"
